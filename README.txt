محاكي القيادة والفتيس اليدوي
=============================

محتويات المشروع:
- index.html : صفحة اللعبة
- style.css  : التصميم
- app.js     : منطق اللعبة
- manifest.json : بيانات تثبيت PWA
- service-worker.js : التخزين المؤقت للعمل دون اتصال بعد أول زيارة عبر HTTPS أو localhost

التشغيل:
1. فك ضغط الملف.
2. افتح index.html في المتصفح لتجربة اللعبة.
3. لتفعيل التثبيت والعمل دون إنترنت، ارفع الملفات إلى GitHub Pages أو استضافة HTTPS.
4. تأكد أن جميع الملفات في نفس المجلد.

ملاحظة:
هذه نسخة أولية بمحاكاة قيادة مبسطة وليست محاكاة فيزيائية احترافية.
